AI-Powered Smart Onion Storage Monitoring & Environmental Control System
Onichan is a smart storage system that uses **IoT, AI, and automated environmental control** to monitor onion storage conditions, detect potential spoilage risks, and help extend onion shelf life.

Features
Temperature & humidity monitoring
Automatic ventilation and environmental control
AI-based spoilage and sprouting risk analysis
Computer vision for fungal/spoilage detection
Pest activity monitoring
Farmer dashboard with alerts and recommendations
Power-failure monitoring

Technologies
ESP32 • Python • Flask • HTML • CSS • JavaScript • AI/ML • Computer Vision • SQLite

Goal
To reduce post-harvest onion losses through **smart monitoring, early detection, and automated storage control**.
